## 产品定义

把股市的**盘面行情、新闻快讯、个股异动**，转化成**体育比赛解说员的口吻**来表达，做成盘中"直播"。

- 支持**多种解说风格**（专业体育解说 / 脱口秀腔 / 情绪化散户等）
- 支持**名人风格的虚拟解说**（脱口秀演员、体育明星、影视明星）——但请按交接文档 §4 的合规红线：做「气质相似的风格标签」，**不要在 prompt 里写具体人名**
- 一期只做**纯文字版**：获取行情 → 转化解说词 → 页面营造直播感（不涉及音频）

## 关键架构纪律（别踩错，这是预研的核心结论）

**生成永远在本地，CF 只做分发。** 因为 Cloudflare Workers 免费版 Cron 触发 CPU 上限只有 **10ms**，把 LLM 调用塞进 Worker 会撞墙，届时既不能真直播也不能伪直播，只能重写。

一期（纯文字、零音频）的推荐形态是**本地验证版**：
```
本地脚本采集行情(多源兜底) → LLM 生成解说词 → 静态页展示直播感
```
理由：整个项目**唯一的真不确定性是"解说词像不像球赛"**，这与直播流、音频、CF 部署全都无关。先用最小成本验证它，不满意可零成本止损。CF/云端等验证满意后再上（二期声音、三期上主站 /live）。
